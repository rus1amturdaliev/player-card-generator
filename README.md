# Player Card Generator

Генератор карточки киберспортсмена: вводишь ник, звание, роль, ранг и статистику, выбираешь стиль (Neon, Gold, Ice), по желанию добавляешь фото и скачиваешь готовую карточку в PNG.

Всё работает прямо в браузере на HTML и Canvas, без сборки и серверов. Фото не загружается в интернет.

## Запуск

Открой `index.html` в браузере.

## GitHub Pages

1. Залей файлы в публичный репозиторий.
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
3. Через минуту сайт появится по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Свои стили

В `index.html` в объекте `S` у каждого стиля свои цвета: `a` и `b` (акценты), `bg` (фон), `t` (текст). Добавь новый стиль и кнопку с `data-s="название"`.
